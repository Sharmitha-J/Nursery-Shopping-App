Paradise Nursery Shopping Application

An elegant React-based e-commerce landing page and shop for houseplant enthusiasts.

Features
Landing Page: Stylish entry point with company history.
Product Listing: Categorized plants with dynamic "Add to Cart" functionality.
Shopping Cart: Full CRUD operations (Add, Update Quantity, Delete) with real-time total calculation.
State Management: Powered by Redux Toolkit.

Tech Stack
- React
- Redux Toolkit
- CSS3 (Responsive Design)
